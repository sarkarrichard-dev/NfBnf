# Start Here

Use `Launch Trading AI Dashboard.cmd` to open the app.

The important folders are:

- `dashboard` - what you see in the browser.
- `trading_ai_engine` - the working brain of the app.
- `Your Trading Data` - private data, model files, and memory.
- `Files To Teach AI` - files you want the AI to inspect.
- `guides` - notes written for humans.
- `learning_examples` - optional examples for Hugging Face dataset work.

You do not need to open the engine folder unless you are changing code.
